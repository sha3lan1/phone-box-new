# جَمعة (JAMAA) — منصة الألعاب الجماعية

## رابط الدخول المباشر
https://rawcdn.githack.com/sha3lan1/phone-box-new/6da421bf411760dd8eab7804d1f8a5c939ff6d0e/jamaa/index.html

## الملفات
- `index.html`: واجهة اللعب الفعلية، بخطوط عربية وهوية زيتية وذهبية.
- `supabase/functions/jamaa/index.ts`: مصدر الدالة التي تستقبل عمليات الإدارة.
- `supabase/schema.sql`: مخطط قاعدة البيانات.

## QR للبكجات
- الرئيسي: رابط الدخول أعلاه.
- الشباب: أضف `?type=youth`
- البنات: أضف `?type=girls`
- العائلة: أضف `?type=family`

## الوظائف
- اختيار نوع القعدة، إنشاء جلسة برمز أو الانضمام لجلسة.
- تصويت مباشر بين الأجهزة وتحديث المشاركين.
- ألعاب مبدئية: مافيا، برا السالفة، مين الأكثر احتمالًا، تحديات سريعة، تمثيل، معلومات عامة، مين أنا، وصراحة أو تحدّي.
- لوحة الإدارة تعدّل نصوص وصورة الواجهة، وتدير الألعاب وتولّد QR.
- Supabase Postgres + Realtime + Storage لحفظ البيانات.

## ملاحظات
واجهة HTML تُخدم عبر CDN لملفات GitHub مع نوع المحتوى الصحيح. عمليات الإدارة تُرسل إلى Edge Function في مشروع Supabase `jfnjrbusifhjzzaxvtvw`. عند تعديل ملف الواجهة، حدّث رابط CDN المثبّت في هذا الملف وأعد توليد أكواد QR للنسخة الجديدة.
