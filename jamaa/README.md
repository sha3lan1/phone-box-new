# جَمعة (JAMAA) — منصة الألعاب الجماعية

**الموقع المباشر:** https://jfnjrbusifhjzzaxvtvw.supabase.co/functions/v1/jamaa

واجهة عربية للموبايل بهوية زيتية وذهبية، اختيار نوع الجلسة، إنشاء جلسات برمز، تصويت مباشر، ألعاب جماعية، ولوحة إدارة لصورة الواجهة والألعاب وأكواد QR.

## الملفات
- `supabase/functions/jamaa/index.ts`: Edge Function التي تخدم الواجهة وعمليات إدارة الموقع.
- `../` في المشروع الأصلي: واجهة العملاء ولوحة الإدارة والألعاب.

## البنية
- Supabase Edge Functions لاستضافة واجهة العميل وواجهات الإدارة.
- Supabase Postgres للجلسات، المشاركين، الأصوات، الألعاب وإعدادات الموقع.
- Realtime لتحديث التصويت وقائمة المشاركين مباشرة.
- Storage لحفظ صورة الواجهة التي يرفعها المدير.

## الأمان
- مفتاح `publishable` فقط موجود داخل الواجهة؛ لا تضع مفتاح `service_role` في HTML أو ملفات عامة.
- عند نشر نسخة جديدة من الدالة، اضبط `JAMAA_ADMIN_PIN` كـ secret في مشروع Supabase، ولا تستخدم رمزًا إداريًا داخل مستودع عام.
- سياسات قاعدة البيانات مفعّلة. الجلسات عامة بالرمز، وهي مناسبة للنسخة الأولية؛ قبل التوسع التجاري الكبير يفضّل نقل حسم التصويت وتوزيع الأدوار إلى عمليات خادمية تتحقق من المضيف.

## تشغيل نسخة الدالة
1. انسخ `supabase/functions/jamaa/index.ts` إلى مشروع Supabase.
2. اضبط `JAMAA_ADMIN_PIN` في Secrets.
3. انشر الدالة باسم `jamaa` مع `verify_jwt = false` لأن واجهة اللاعبين عامة.
4. نفّذ مخطط قاعدة البيانات المرفق/الموجود في إعداد المشروع.
